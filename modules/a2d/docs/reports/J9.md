## 5. Écarts et incidents

1. **HEAD de départ ≠ `29d5d0f`** — voir §1. Aucun commit réécrit, aucune
   action destructive ; le snapshot `archive/pre-restructure-J8` pointe bien sur
   `29d5d0f`.
2. **`pytest` et la capture stdout sur DrvFs** (`/mnt/d`) : la capture globale
   échoue (`FileNotFoundError` sur `truncate` d'un fichier temporaire déjà
   délié). Les exécutions locales ont donc utilisé `--capture=no` ; la CI
   (ext4) n'est pas concernée. **Ce n'est pas un défaut du code du dépôt.**
3. **`sys.path.insert` supprimés partout** : les CLI et les tests importent
   désormais le paquet installé → `pip install -e .` est **préalable** à toute
   exécution (ajouté à la CI et documenté dans `AGENTS.md` / `README`).
4. **Caches du harnais restés à l'ancien emplacement** : `harness/dream/{.venv,.fork,.cache}`
   (≈ 8,4 Go, ignorés par git) n'ont pas suivi le déplacement ; le venv
   contient des chemins absolus. Reconstruction au nouveau chemin =
   **accord utilisateur requis** (listé « À TRANCHER »).
5. **Empaquetage non trivial** : `academiia.a2d` est installé depuis
   `modules/a2d/a2d` et `academiia.a2d.eval` depuis `modules/a2d/eval` (mapping
   `package-dir`). Vérifié en installation réelle (`pip install -e .`), y
   compris dans un venv vierge CPU ; pas de repli `import a2d` n'a été
   nécessaire.
6. **Changements de fins de ligne** : plusieurs fichiers étaient en CRLF ; la
   réécriture de chemins les a convertis en LF. Les conversions **pures**
   (aucun autre changement) ont été **annulées** pour ne pas polluer le
   diff ; les fichiers réellement modifiés sont en LF.
