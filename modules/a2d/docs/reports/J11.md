## 10. Écarts constatés (déclarés)

1. **Transport SSH** : l'environnement WSL n'a **aucune clé SSH** (`~/.ssh` ne contient
   que `known_hosts`) ni helper de credentials ; `git push` échouait avec
   `Permission denied (publickey)`. Les pushes ont été réalisés via le binaire
   **Windows** `ssh.exe` (clé `C:\Users\sjteb\.ssh\id_ed25519`, authentifié
   `zenhit777`). Conséquence : `github.com` a été ajouté aux `known_hosts` **Windows et
   WSL** (écritures hors dépôt, nécessaires à la connexion ; aucune donnée du dépôt modifiée).
2. **Test rouge intermédiaire (non commité)** : après la suppression des doublons de
   `eval_compare.py`, `test_strip_reasoning_removes_diffusion_prefix` échouait
   (`AttributeError: module 'academiia.a2d.eval.eval_compare' has no attribute
   'strip_reasoning'`). Le test a été réaligné sur la source canonique **avant** commit ;
   **aucun commit rouge n'a existé**, aucun revert n'a été nécessaire.
3. **PEP 668** : `pip install -e .` est refusé sur le Python système (environnement
   *externally managed*) ; la vérification s'est faite dans un venv **dans le dépôt**,
   `_artefact/venv-dev` (`--system-site-packages`, `--no-deps`). La CI, elle, installe
   normalement via extras sur 3.12.
4. **`requirements.txt` n'installe plus de paquets** (pointeur) : un environnement qui
   faisait `pip install -r requirements.txt` n'installera plus rien — c'est l'effet
   recherché (« une seule vérité de versions »), à connaître.
5. **M3 reporté** (ADR-004) : `import academiia.a2d` tire toujours `torch` (≈ 1,2 s).
